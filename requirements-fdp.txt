# WHY THIS FILE EXISTS — the original Module-1/requirements.txt breaks the environment:
#   * it pins `torch==2.6.0`, which makes pip REPLACE the image's CUDA build
#     (torch 2.5.1+cu124) with a PyPI wheel -> CUDA is lost and torch ends up broken
#     (pip left a corrupt `~orch` dir; `pip check` then reports "torch is not installed"
#     for accelerate / peft / bitsandbytes / torchvision / torchaudio).
#   * the resulting numpy/scipy ABI mismatch raises
#     "All ufuncs must have type `numpy.ufunc`. Received (<ufunc 'sph_legendre_p'>...)"
#     which makes `import transformers` and `import diffusers` fail outright
#     -> Lab 2 (12 cell errors) and Lab 3 (10 cell errors) cannot run.
#   * it pins `faiss-gpu-cu12`, unnecessary here (faiss-cpu is enough for the lab corpora).
#
# GOLDEN RULE: **never install/upgrade `torch` on this image.** It already ships
# torch 2.5.1+cu124 built against the node's CUDA 12.8 driver. Everything below is
# chosen to be compatible with that build.
#
# Install with:
#   pip install -r requirements-fdp.txt
#
# Verify afterwards (all three must be True):
#   python -c "import torch, transformers, diffusers; print(torch.__version__, torch.cuda.is_available())"
